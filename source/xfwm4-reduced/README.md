# Vault.OS-Reduced xfwm4

Same decoration layout as Vault.OS (28px titlebar, 22×22 buttons), using the reduced-phosphor palette from `tokens-reduced.css`.

Copy to `~/.themes/Vault.OS-Reduced/xfwm4/` and set the xfwm4 theme to `Vault.OS-Reduced` whenever the GTK theme is `Vault.OS-Reduced`.

Regenerate latches with `python3 source/xfwm4/gen_buttons.py`.
