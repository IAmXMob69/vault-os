# Vault.OS xfwm4

XFCE window decorations for Vault.OS.

- Titlebar height 28px; buttons 24×24
- Active window: phosphor title text and a 1px focus rail under the title
- Inactive window: steel title text; close button stays steel on inset (not red)
- Active close: red stop-shaped plate with a heavy X
- Pixel colors are `#RRGGBB` plus an xfwm symbolic name

Install by copying this directory to `~/.themes/Vault.OS/xfwm4/` and setting the xfwm4 theme to `Vault.OS`.
