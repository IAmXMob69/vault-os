# Terminal readability

Default text is phosphor `#1AFF6B` on vault-black `#070807`. Bloom, scanlines, and persistence stay optional — you can read the terminal without them.

If CRT effects get in the way, switch to `reduced` or `clear`:

```bash
vaultos-terminal-phosphor reduced
```

Focus rings live in the panel/GTK chrome, not in the glow. Desktop and lock spin have their own dials; the terminal mode does not freeze them.
