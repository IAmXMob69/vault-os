# TRM-05 terminal phosphor layers (a11y)

Hard rules (Accessability Bot):
1. Default readable: `#1AFF6B` on `#070807`
2. Bloom / scanlines / persistence never required to understand UI
3. Visible focus without relying on glow alone (GTK-02 / HUD-04)

## Dial

```
vaultos-terminal-phosphor full      # CRT scanlines + bloom
vaultos-terminal-phosphor reduced   # solid well, bevel, no bloom (default)
vaultos-terminal-phosphor clear     # sharp phosphor only
vaultos-terminal-phosphor status
```

State: `~/.config/Vault.OS/terminal-phosphor`
HUD/GTK may call the script. Reopen Terminal after a mode change so VTE CSS paints.

## Desktop Arch mark (`vaultos-spin-arch`)
- `full` → Y-axis coin spin (PERIOD=8)
- `reduced` / `clear` / `--reduced-phosphor` / ThemeName `Vault.OS-Reduced` → static mark, effects off
- Force spin: `vaultos-spin-arch --full`
- Vault 111 spinner stays Hidden

## Desktop Arch mark vs terminal CRT
- Terminal dial (`vaultos-terminal-phosphor`) stays reduced/clear/full on its own.
- Desktop homescreen mark: `vaultos-spin-arch --full --instance desktop` (Blaine wants spin). Do **not** relaunch the desktop instance with `--reduced-phosphor`.
- Lock/screensaver: spins by default (`--full`); static only when ThemeName is `Vault.OS-Reduced`. Terminal phosphor dial alone does not freeze lock.
